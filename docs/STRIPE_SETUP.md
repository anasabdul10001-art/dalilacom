# إعداد الدفع الدوري في دليلكم

تستخدم باقات الموقع والتطبيق مسارات موحّدة عبر Stripe وPayPal. بعد نجاح الدفع يرسل مزود الدفع إشعارًا موقّعًا إلى دليلكم، فيُفعَّل الاشتراك المرتبط بالخطة تلقائيًا. السعر يؤخذ من سعر الخطة أو استثناء الدولة الموجود في `PlanPrice`.

## المطلوب من صاحب الحساب

1. أنشئ حساب Stripe للنشاط التجاري وأكمل التحقق الذي يطلبه Stripe.
2. من Stripe Dashboard انسخ المفتاح السري وضعه في إعدادات الاستضافة باسم `STRIPE_SECRET_KEY`.
3. عيّن `PUBLIC_APP_URL` إلى عنوان الموقع الفعلي، مثل `https://dalilacom.com`.
4. أنشئ Webhook بعنوان `https://dalilacom.com/billing/webhook/stripe`، واشترك بهذه الأحداث:
   - `checkout.session.completed`
   - `invoice.paid`
   - `invoice.payment_failed`
   - `customer.subscription.deleted`
5. انسخ سر توقيع Webhook إلى `STRIPE_WEBHOOK_SECRET`.
6. فعّل وسائل الدفع المناسبة لحساب Stripe، ومنها البطاقات وSEPA Direct Debit إذا كانت متاحة لبلد النشاط.

## PayPal

1. أدخل `PAYPAL_CLIENT_ID` و`PAYPAL_CLIENT_SECRET` في إعدادات الخادم.
2. أنشئ خططًا دورية داخل PayPal لكل باقة. انسخ معرّف كل خطة إلى خانة «معرّف خطة PayPal» في لوحة السوبر أدمن.
3. أنشئ Webhook إلى `https://dalilacom.com/billing/webhook/paypal`، وانسخ معرّفه إلى `PAYPAL_WEBHOOK_ID`. اشترك بأحداث تفعيل الاشتراك، الدفع الناجح، فشل الدفع، إلغاء الاشتراك وانتهائه.
4. أثناء الاختبار غيّر `PAYPAL_API_BASE` إلى `https://api-m.sandbox.paypal.com` واستخدم مفاتيح Sandbox وخطط Sandbox.

المفاتيح سرية وتُحفظ في إعدادات الخادم فقط. لا تضعها في تطبيق Android أو ملفات الواجهة العامة. إلغاء التجديد متاح من بيانات الاشتراك؛ ويبقى الوصول فعّالًا حتى نهاية الفترة التي دفعها العميل.

> لا يمكن تفعيل التحصيل الفعلي قبل إدخال مفاتيح المزود وتسجيل Webhook على الاستضافة. يلزم أيضًا إنشاء خطة PayPal لكل باقة؛ ووسائل الدفع المتاحة تعتمد على بلد الحساب ومراجعته.
