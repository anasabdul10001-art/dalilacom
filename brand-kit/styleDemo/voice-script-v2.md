# نص الفيديو v2: يوم صاحب النشاط (مسودة للموافقة)

القواعد: «صاحب النشاط» مو «تاجر»، «زبون» مو «عميل»، «حسم» مو «خصم». بس ميزات موجودة فعلاً (تسجيل الدخل والمصاريف، تصوير الفاتورة ومراجعتها وتأكيدها، ملخّص الشهر، الصافي لكل عملة). بدون وعود غير جاهزة.
التوزيع: الجمل الشامية بصوت غيداء، وكلام دليلكم بصوتك بالفصحى. كل التشكيل حسب `dialect-notes.md`.
