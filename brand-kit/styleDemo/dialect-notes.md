# Owner's Syrian dialect: corrections for voice-over text (grows with every round)

Rules the owner gave while testing the cloned voice (ElevenLabs v4, 2026-11-16):

1. Write scripts the way he writes in chat: Syrian colloquial spelling + light tashkeel on tricky words.
2. Brand name ends with meem: دَلِيلكُم (never ـكن). Avoid "ياهن كلهن" next to it.
3. "ربحت" is read with a stressed ح by default: write رِبحِت.
4. Final kaf stays SAKIN (Syrian): دَخلَك، مصاريفَك، بِنَفسَك. A full vowel on the last kaf (مصاريفَكَ) sounds Saudi/Gulf.
5. Very short lines ("سجّل دخلك.") get misread ("سجله دخلك"): merge them into one longer sentence.
6. Delivery must be energetic, not lecture-like: low Stability (about 25%), tag [excited], end with "!".
7. Open question: "راجِعها" still sounds wrong to him; ask how he says it.
8. Voice split (owner decision 2026-11-16): the Syrian-dialect parts use the library female voice "Ghaida - Friendly, Charming and Caring" (Arabic/Syrian, upbeat); the owner's own cloned voice is used ONLY for Fusha.
9. The pronunciation problems are in the written text, not the voice: always add careful tashkeel (damma, fatha, kasra, sukun) so the Syrian reading comes out right. "ربحت" tests: رِبحِت (wrong), ربِحت / ربحت / كسبت (files hook-ghaida-A/B/C; waiting for the owner's pick).
